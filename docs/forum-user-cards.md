# 论坛身份展示

发帖和回复默认使用独立匿名身份。发布时可逐条开启实名模式，显示论坛用户名、头像和原生名片。论坛管理员及委派的树洞管理员可开启管理员视角，查看帖子与回复的真实作者；普通用户不能通过请求参数开启此视角。旧审计操作者及发言限制用户仍沿用论坛名片。

使用 Discourse 原生 `DUserLink`、`DUserAvatar` / `dAvatar` 和 `data-user-card`，遵循论坛用户资料可见性设置。只序列化已授权身份的 `id`、`username`、`avatar_template`，不带邮箱等私有字段。`public_author` 字段显式记录每条内容的实名选择，迁移默认 false，旧内容不会变为实名；不使用历史回复中含义不一致的 `anonymous` 字段判断公开授权。

2026-09-22 隔离验证：6 项后端身份/匿名边界测试、103 个断言通过；真实 Chromium 在 1440px 与 390px 验证原生名片弹出、页面不跳转、匿名与历史署名无账号链接、排行榜交易详情仍可打开。测试工具位于服务器 `discourse-community-test/forum_identity_test.rb` 和 `forum_identity_browser.cjs`，只使用隔离库及测试账号。

实名回复不会携带其作者的匿名别名；实名洞主再次匿名回复时也不会标为洞主。关闭管理员视角会清空页面数据缓存，服务端响应禁止缓存。
