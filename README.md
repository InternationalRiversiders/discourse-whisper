# Discourse Whisper · 树洞

树洞的 Discourse 原生插件：Rails/PostgreSQL 后端、Glimmer 前端、论坛登录和用户组授权、Sidekiq 通知补发。不需要运行旧 Next.js 服务。

入口 `/whisper`。信息流使用论坛式话题列表和楼层回复，身份仍是树洞内独立的“洞主 / 匿名 A、B…”；不会生成带实名作者的普通论坛 Topic/Post。

当前状态：**已于 2026-09-21 完成正式切换。** 兼容验证基于 Discourse `2026.9.0-latest`，核心提交 `5b59681a8c85d1b8cca5c8eac15debc389c53325`。

## 安装

在 Discourse 容器配置的插件克隆步骤中添加本仓库，建议固定已验收的提交，然后按论坛标准流程重建容器。数据库迁移和前端资源编译均不可省略。

```yaml
- git clone https://github.com/InternationalRiversiders/discourse-whisper.git
```

设置：

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| `whisper_enabled` | false | 启用页面、API 和通知任务 |
| `whisper_read_only` | true | 阻止业务写入、上传和通知投递 |
| `whisper_admin_only` | false | 限制为管理员/委派的树洞管理员访问 |
| `whisper_allowed_groups` | 空 | 可访问的论坛组；为空时仅管理员可访问 |
| `whisper_admin_groups` | 空 | 委派树洞审核权限，不授予论坛管理员权限 |

论坛管理员始终具备树洞管理权限，停用/被封禁的账号不能访问。配置访问组并确认导入结果后，再关闭只读模式。安装校友地图插件时，入口加入其共同维护的“校园生活”侧栏分组。

## 功能

- 最新 / 最近回复排序、正文和编号搜索、连续加载、返回列表位置保留。
- 匿名发帖、最多九张图片、匿名回复、引用父回复、稳定帖内别名和楼层链接。
- 互斥赞踩、举报、自己的帖子/回复、历史消息和论坛铃铛。
- 隐藏/恢复/删除、处理举报、树洞禁言、需要理由并公开审计的身份查看。
- 受保护的图片、账号删除/匿名化/合并处理，以及自己的数据导出。
- 随论坛色板适应深色/浅色，支持手机布局。

历史通知保留在树洞消息页，不重新触发论坛铃铛或邮件。树洞内容不进入论坛普通话题搜索、用户发帖历史或常规帖子邮件。举报使用树洞管理页，尚未接入核心 Reviewable。

## 迁移与验证

见 [迁移和设计说明](docs/implementation.md) 与 [验收记录](docs/validation.md)。导出文件、原始数据库、媒体和登录凭据均不得提交到此公有仓库。

业务表统一使用 `river_whisper_` 前缀；停用或卸载代码不会自动删除数据。

## 备份

业务数据和处理后的图片均保存在 Discourse 数据库中，会随论坛完整数据库备份一起保存；无需另设树洞数据库备份任务。恢复时须安装兼容的插件代码并保留对应版本记录。

最新功能核对和通用旧链接参数修补见 [最终复核](docs/final-review.md)。
